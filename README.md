# AI Image Classifier using Python

This is a beginner-friendly AI image classification project. The app allows users to upload an image and predicts what object is in the image using a pre-trained MobileNetV2 deep learning model.

## Features

- Upload JPG, JPEG, or PNG images
- Classifies uploaded images
- Shows top 3 prediction results
- Displays confidence percentage
- Simple web interface using Streamlit

## Technologies Used

- Python
- TensorFlow/Keras
- Streamlit
- NumPy
- Pillow
